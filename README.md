# Estudos de Python: Conceitos Fundamentais e Projetos

Este repositório reúne scripts e pequenos projetos desenvolvidos durante o aprendizado da linguagem Python. O repositório busca consolidar conceitos essenciais de sintaxe, estruturas de dados e lógica de programação através de exercícios práticos.

---

## Conteúdo do Repositório

| Projeto / Conceito | Descrição |
| :--- | :--- |
| **Loop Infinito** | Estudo de estruturas de repetição contínuas, controle de fluxo e condições de parada (`break`). |
| **Manipulação de Strings** | Aplicação de métodos nativos de texto, fatiamento (*slicing*), formatação e concatenação. |
| **List Comprehension** | Prática de sintaxe reduzida para criação, filtragem e transformação eficiente de listas. |
| **Funções Lambda** | Uso de funções anônimas e concisas para simplificação de lógica de código. |
| **Analisador de Notas de Alunos** | Aplicação prática que processa pontuações, calcula médias e valida o status de aprovação. |

---
